# Fight For Nothing

A retro-inspired 2D local multiplayer fighting game built with Unity.

## Game Overview

**Fight For Nothing** is a small-scale arcade fighting game inspired by classic fighting games. Players battle opposing teams, using attacks, blocks while avoiding environmental hurdles.

The game focuses on simple controls, quick matches, and nostalgic arcade-style gameplay.
